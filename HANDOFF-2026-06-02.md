See `CLAUDE.md` "Current sidebar" for the current locked structure.

> **UPDATE 2026-06-02 (session 3, triage-driven):** removed `/home` (root → `/agents`); **Phone Numbers** is now a top-level resource at `/phone-numbers` (not under campaigns); **Campaigns** list is channel-tabbed (All · Inbound · Outbound · WhatsApp · Web); **Realtime Services** = RTE catalog + "View usage" (no Sessions tab — RTE is *usage*; RTC session quality = Agora Analytics, separate product); **agent Sessions** live in the Monitor hub at `/sessions` (Conversational AI runs, not RTC telemetry). Grounded in Agora docs + competitor IA.

Rules that are LOCKED (CLAUDE.md "Don't re-litigate" + this session):
- Label is **"Monitor"**, NOT "Analytics" (collides with the separate Agora Analytics product). The Monitor page *is* the global analytics dashboard.
- **"Observe"/"Build"/"Deploy" are mental clusters only** — rendered as flat groups split by dividers, **no uppercase section-label headers** in the sidebar.
- **Monitoring is global + per-campaign (both/and):** global Monitor/Call History/Chat History are filterable by campaign/agent; each campaign *also* has its own scoped Analytics + Calls in its detail page. Not redundant — different jobs.
- **Chat History ≠ Session History.** Chat History (`/chats`) = text-channel agent conversations (WhatsApp/SMS/web). Session History (`/realtime-services/sessions`) = RTC SDK telemetry (bitrate/region/participants). Different personas, different products.
- Vocabulary locks (from CLAUDE.md): "Channel" = Agora RTC only (never deployment); "Campaign" = inbound queue / outbound dialing program; "Deploy" = the go-live moment; "Secured mode" = App Certificate/token auth. No phone-call metaphors in agent UI ("Talk to agent", not "Start Call").
