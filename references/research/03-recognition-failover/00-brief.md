## Agora fact-check (agora-agents@2.4.0 `node_modules/agora-agents/dist/cjs/api/types/*.d.ts` + docs.agora.io, 2026-09-10)

- `asr.vendor` — 15 vendors (`Asr.d.ts`): ares · fengming · tencent · microsoft · deepgram · openai · google · amazon · assemblyai · speechmatics · sarvam · xai · xfyun · xfyun_bigmodel · xfyun_dialect.
- `asr.language?: AsrLanguage` on every vendor wrapper — "The BCP-47 language tag identifying the primary language used for agent interaction." 32 tags (`AsrLanguage.d.ts`): ar-EG ar-JO ar-SA ar-AE bn-IN zh-CN zh-HK zh-TW nl-NL en-IN en-US fil-PH fr-FR de-DE gu-IN he-IL hi-IN id-ID it-IT ja-JP kn-IN ko-KR ms-MY fa-IR pt-PT ru-RU es-ES ta-IN te-IN th-TH tr-TR vi-VN. **One primary language; no list, no `multi`, no auto-detect at the contract level.**
- `asr.keywords` — release notes https://docs.agora.io/en/ai/release-notes, **v2.11 (August 11, 2026)**: "You can now configure keywords to improve ARES's recognition accuracy for specific terms, such as brand names, product names, or industry jargon." "Configure keywords using the `AresSTT` vendor in the Agora Agents SDKs, or the `keywords` parameter within the `asr` block directly through the RESTful API." REST row: "`asr.keywords`: ASR keywords used to improve recognition accuracy for specific terms. Only available when `asr.vendor` is not set or `ares`". SDKs: Python "`AresSTT`: New `keywords` parameter", TypeScript "New `keywords` option", Go "`NewAresSTT`: New `Keywords` field". **Shape (array of strings? weights? limit?) is not stated in the notes and is not typed in the installed SDK 2.4.0** (`AresAsrParams = Record<string, unknown>`, `AresAsr` has no `keywords`). v2.10 (July 30, 2026) has nothing on ASR. Earlier v1.x notes mention "Keywords" as a Beta for "proprietary words" with no structure. → Assume `string[]` (matches `interruption.keywords_config.trigger_keywords: string[]` and Microsoft `phrase_list: string[]`); confirm with Engine before the slice leaves `design/sandbox`.
- Deepgram `asr.params.keyterm?: string | null` (`DeepgramAsrParams.d.ts`) — "Boost specialized terms and brands for Deepgram." Agora vendor page (reachable via https://docs.agora.io/en/conversational-ai/models/asr/overview → `/en/ai/models/asr/deepgram`): "Boost specialized terms and brands. Only compatible with the `nova-3` model." It is a **single string**; Deepgram's own API takes repeated `keyterm` params (multi-word phrases joined with `%20`, "Limited to 500 tokens per request", "accepts plain terms only—it does not support weights or intensifiers", recommends "the most important 20-50 terms" — https://developers.deepgram.com/docs/keyterm). **How Agora separates several terms inside one string is undocumented.**
- Microsoft `asr.params.phrase_list?: string[] | null` (`MicrosoftAsrParams.d.ts`) — "Words or phrases to improve recognition accuracy". `language: string` and `region: string` required.
- OpenAI `asr.params.input_audio_transcription.{model, prompt, language}` (`OpenAiInputAudioTranscription.d.ts`) — `prompt`: "Prompt that guides the transcription process". A vocabulary can ride in the prompt, but it is a prompt, not a list.
- Sarvam `asr.params.language: string` — "Set to unknown for automatic language detection." **The only auto-detect in the contract**, one vendor, no allowed-set.
- Amazon uses `language_code` (not `language`); Tencent has no language field at all (`engine_model_type`, `voice_id`); Fengming params are untyped.
- **Not in the contract:** any denoise field (nearest is `parameters.audio_scenario` = default | chorus | aiserver, which is an audio profile, not denoising; `[O1.5] Disable client-side AINS` is Engine work); ASR-side pronunciation (only TTS MiniMax `pronunciation_dict.tone`); a language list / runtime switching (868kykbfg → Requires Engine); a transcriber fallback field (868kyv45t → the Console-side pool is 07's row).
- Docs reachability: https://docs.agora.io/en/ai/models/asr/overview → **404**; https://docs.agora.io/en/ai/rest-api/agent/join → 404; the old tree https://docs.agora.io/en/conversational-ai/models/asr/overview exists and documents **only Deepgram** with `keyterm` + `language`; https://docs.agora.io/en/conversational-ai/rest-api/agent/join exists (shows `asr.vendor · language · params · credential_mode`; `keywords` not in the fetched excerpt).

## Competitor evidence (public docs, 2026-09-10)
- **Vapi** — custom keywords https://docs.vapi.ai/customization/custom-keywords: Deepgram `keywords` ("single-word tokens", intensifier `"apple:3"`) vs `keyterm` (multi-word, no intensifier); AssemblyAI `keytermsPrompt` "Up to 100 keyterms per session, each up to 50 characters"; "Keywords should be uncommon words or proper nouns not frequently recognized by the model." Per-provider fields, no unified list. Transcriber fallback https://docs.vapi.ai/customization/transcriber-fallback-plan: `transcriber.fallbackPlan.{autoFallback.enabled, transcribers[]}`; "Manual fallbacks first — … Vapi tries each one sequentially in the order you specified"; "each fallback transcriber can have its own language configuration"; dashboard: "Select the Advanced tab. In the Fallbacks section, locate Fallback Transcriber." Multilingual https://docs.vapi.ai/customization/multilingual: Deepgram nova-2/3 `"language": "multi"`, Google `"Multilingual"`; the allowed set is stated in the system prompt, not enforced. (https://docs.vapi.ai/customization/custom-transcriber and /assistants/fallback-providers → 404/off-topic.)
- **Retell** — create-agent API https://docs.retellai.com/api-references/create-agent: `boosted_keywords` array of strings — "Provide a customized list of keywords to bias the transcriber model, so that these words are more likely to get transcribed." (provider-agnostic, no weights); `language` single locale | array | deprecated `"multi"` (stored as ten locales), default `en-US`; `stt_mode` fast | accurate | custom; `vocab_specialization` general | medical — "This setting only applies for English agents"; `pronunciation_dictionary[{word, alphabet ipa|cmu|pinyin|jyutping, phoneme}]`; `denoising_mode` no-denoise | noise-cancellation (default) | noise-and-background-speech-cancellation; **no fallback transcriber field** (only TTS fallback, /build/tts-fallback). Language https://docs.retellai.com/agent/language + /agent/multilingual: "A single-language agent is the most accurate setup"; multiselect picker of "the exact set of languages"; "Unsupported combinations are greyed out in the language picker, with a tooltip explaining which voice or voice model is blocking it."; Cantonese vs Mandarin caveat. Noise https://docs.retellai.com/build/handle-background-noise: the aggressive mode "incurs a $0.005/min surcharge" and "will hinder the ability of your agent getting interrupted". Pronunciation https://docs.retellai.com/build/add-pronunciation: "applies exclusively to how agents pronounce words during TTS generation, not to input speech recognition." (/build/boosted-keywords and /reliability/increase-transcription-accuracy → 404.)
- **ElevenLabs** — https://elevenlabs.io/docs/eleven-agents/customization/voice/customization/language: `conversation_config.agent.language` (primary) + `conversation_config.language_presets` with `overrides` (first_message, voice); language "fixed for the duration of the call" unless the detection tool is on. https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/language-detection: "The languages that the agent can switch to must be defined in the `Agent` settings tab."; `only_at_conversation_start` limits switching to "the first two user turns"; caveat "background speech or an unusual accent can occasionally trigger a switch the caller did not intend". (Older `/agents-platform/...` URLs → 404.)
- **Deepgram** — https://developers.deepgram.com/docs/keyterm: `keyterm`, Nova-3 + Flux, "Limited to 500 tokens per request", plain terms only, "the most important 20-50 terms".

**Patterns to take (5).** (1) *One vocabulary list, mapped per vendor* — Retell's one `boosted_keywords` beats Vapi's per-provider fields; the mapping table above is the Agora version. (2) *Dead-not-hidden with the blocker named* — Retell's greyed-out language combos with a tooltip naming the blocking voice; same idiom as 07's ineligible backups. (3) *Single language is the accurate default; the allowed set is a list of exact locales, and switching is limited to it* — Retell + ElevenLabs agree; Vapi's prompt-only allowlist is the anti-pattern. (4) *Fallback transcriber = ordered list where each member may carry its own language, under Advanced › Fallbacks* — Vapi; 07's row already is this, with language eligibility. (5) *"Test a representative phrase before publish"* — required by 868kytr56, offered by no competitor as a control (whitespace); the Console's Test rail already streams `You:` transcripts, so the check is a comparison, not a new transport.
