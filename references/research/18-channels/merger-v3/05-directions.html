Five directions for "a campaign is a run of the agent" inside the existing Console

All five are v3: no new capability, no token or primitive the live Console lacks. The audit of 2026-09-21 fixed the model (campaign = run of the agent) and the IA (keep Outbound Campaigns as the runs index). The question left is how the two sides point at each other.

A · Links only

Make every agent name that appears on a run a link to the agent, and nothing else. Runs index cell, detail banner, detail configuration, form label. Zero new surfaces, one helper that maps telephony uuid to Studio id through the deployed-agents index. Weakness: the link lands on the agent's Test tab, where nothing about runs is visible, so the door opens onto the wrong room.

B · Links plus a rail door (chosen)

A, plus ?rail=deploy so the link opens the Deploy rail where the agent's campaigns already sit (b695f33c), plus a Campaigns count on the agents list that opens the runs index filtered to that agent. Every door is an existing control extended; both directions read the same two indexes. Weakness: the count is computed on the client from a 100-row campaign page, so a project with more than 100 campaigns undercounts until the API grows an aggregate.

C · Campaigns tab on the agent

Add a fifth top tab, Campaigns, next to Prompt · Models · Advanced · Actions, holding the full runs table filtered to the agent. Strong for the operator who lives in one agent. Weakness: a second inventory of runs, the exact defect the audit scored sev 4 on Studio X 2; two tables that must agree on columns, filters and row menus forever.

D · Agent header on the campaign form

Replace the AI agent select with a card: avatar, name, status chip, version, Change. Reads well when arriving from the agent. Weakness: a new component for a field that already has a labelled option row with meta (agtid · project · AppID); the card duplicates the option label and the Change button is a second door to the same select. Version is not in the deployed-agents record, so the card would print a value the contract cannot produce.

E · Fold campaigns under Agents in the sidebar

Move Outbound Campaigns from Launch to a child of Agents, or into the agent page only. Weakness: this is Studio X 2's IA, rejected on 2026-09-21; every competitor keeps a top-level campaign list; legacy routes and bookmarks point at /telephony/campaigns.

Verdict

B. It is the only direction that closes the loop in both directions with controls that already exist: a cell becomes a link, a tab becomes URL-addressable, a list gains a count that opens a filter the list already supports. It adds one helper file and one search param. The one thing it cannot do, count past 100 campaigns, is an API gap to log, not a reason to draw a card the contract cannot fill.
