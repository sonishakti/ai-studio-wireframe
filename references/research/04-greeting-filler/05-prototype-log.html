Deviations from the mock, and why

  • Disclosure is OFF by default for every agent, including new ones. The directions recommend ON for new agents; that is owner question 1 and it needs the legal sign-off on the sentence first. Turning it on never rewrites a saved greeting silently — the builder sees the composed line change as they flip the switch.
  • No preview-gate change. The mock implies caller-first should be previewable; the gate at agent-editor-workspace.tsx still blocks an empty greeting. Left alone in this slice — it is a shared code path with the create flow. Logged as next.
  • The hardcoded “Thanks for calling…” fallback stays. agent-detail-page.tsx substitutes it when an agent has no greeting, which fights caller-first. Not touched: it is pre-existing behaviour outside this direction. Logged as a finding.
  • Static preview turn order not fixed. The mock preview shows the caller before the agent; unrelated component, logged.
  • Verdict line is a duration, not a transcript. “Hear the opening” prints Opening · {n} s from the live preview's own agent-state transitions. The directions' richer transcript line would need preview internals changed.
