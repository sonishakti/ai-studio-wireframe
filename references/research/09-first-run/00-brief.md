### Patterns (what to take)

1. **Everyone walls first-run behind create-an-agent; nobody pre-provisions.** Vapi and Retell both start at an empty Agents list + a template picker. Aria-on-signup (LEARNINGS A1) is still whitespace — and ng-console today also lands on an empty list.
2. **Test-before-telephony is table stakes** (Retell "Test" web call, Vapi "Talk"). A first run should end on a test call, not a saved agent (A3 rule: provisioning success ≠ call success).
3. **Four fields carry, the rest is vendor plumbing.** Prompt · greeting · voice · model port cleanly; a typical Vapi assistant maps ~14 of ~20 populated fields. The product is the honesty of the other six.
4. **Scalars vs milliseconds.** Retell `responsiveness` / `interruption_sensitivity` (0–1) and Vapi seconds must be *approximated* to Agora presets and shown under "Changed" — never silently.
5. **`{{var}}` is the lingua franca**; Retell splits agent from LLM (two GETs) → accept two pastes or a merged object; **no vendor puts a key in the agent JSON** (Vapi `credentialIds` are org refs) → import can never carry a secret — the same rule the recipes task states.

## What we need (user-visible)

- A third way to start in the create modal: **Import from Vapi or Retell** — paste JSON or upload a file; keys are never imported.
- A **mapped / changed / not imported** report before anything is created, every dropped row with a reason and a pointer in our vocabulary; credential gaps as blockers, not surprises.
- The imported agent is a **real agent** in the builder, with a one-line recap ("Imported from Vapi · 14 of 17 settings") and the report one click away.
- Opening an agent with **retired config** offers **one click to update it** to the current contract, showing before/after, then says it must be republished.
- One honest **default answer for turn detection** (balanced) across draft, template and create modal.
- The **four onboarding stages** instrumented with elapsed time and failure reason, and a one-line first-success recap on Home.

## Tech requirements

- **Importer** `src/lib/agents/agent-import-mappers.ts`: input = pasted JSON string or `File` (`.json`, ≤1 MB) · `detectVendor()` on shape (`transcriber`/`model.messages` → vapi; `response_engine`/`voice_id` → retell; else unsupported) · output `{ name, properties (join contract, canonical shapes only — never emits a retired key), agentType, report: { mapped[], changed[], dropped[] } each row `{ theirs: path, ours: LANDS label, value?, reason? }`, needsCredential: [{ section, vendor }] }`. `LANDS` labels use ng-console tab vocabulary (Prompt · Models · Advanced › Turn Detection / Interruption / Silent reminder · Actions › Tools / Knowledge · Custom config). `DROP_REASONS` is a single table; a field with no entry cannot be dropped silently (test asserts every dropped path has a reason).
