Rationale

  • Two real controls have no UI today. idle_timeout round-trips through save with no control; farewell_config is absent. A ships both as sentences in the existing row grammar — real value on day one, zero new chrome.
  • The Console already holds silence and duration rules in two layers with no relation stated. A's captions ("Set per phone number · Edit →") and D's ladder check make the relation visible instead of adding a third copy that can drift.
  • Honesty floor. Inert options sit inside a live sentence, dashed and captioned "Requires Engine" — the roadmap is legible without a fake card (E rejected; its content becomes one line in the docs).
  • D reuses what exists. validateAgentDetailDraft and both contract validators already produce the codes; the Publish toast becomes a list with Fix→, exactly the v7 lock and the 868keazr7 note "Needs-attention preflight already exists".
  • Competitors agree on the shape (one group on the agent · voicemail = hang up | leave a message · DTMF as a tool). The one-line ladder before go-live is the whitespace nobody fills. B's Status words survive as A's captions; C stays the home of number-level values and A links to it.

Dependencies, stated on the row

  • Engine: agent-level max duration, reminder count, call-screening identity (868kytrua) · leave a message (868kgy2n3) · DTMF (868kykbfw). Until then those options are disabled with the caption.
  • Owner call: number values read-only on the agent (proposed) vs an agent-level draft the number inherits. If the draft wins, max duration moves to sessionStorage like the others.
  • Teammate: hiding #1446's Silent reminder row needs a 3-line optional prop on AdvancedSharedSection.
