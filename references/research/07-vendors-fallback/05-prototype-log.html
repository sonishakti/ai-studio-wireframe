Deviations from the mock, and why

  • No region in the gap chip. TTS: no backup in EU became TTS: no backup. ng-console carries no hosting-region / geofence on the agent, so the region clause would be invented. Shortening the reference copy is allowed; adding is not.
  • No "Unpin region" link. Same reason. The owner call (agent property vs deployment property) is still open in 00-brief.md.
  • Vendor label, not vendor + model. The recap says Deepgram · managed rather than Deepgram Nova; the model already sits in the row directly above, and the fallback is a vendor decision.
  • Managed primaries only offer Agora's pool; BYO primaries only offer the user's other keys. Decided in the brief (managed includes vendor usage; BYO fallback needs a second key). Not re-litigated.
  • No info hint. The mock shows an ⓘ next to the label; the reference gives it no text, so it was left out instead of inventing a tooltip.
  • Switch live, Test failover dead. The directions suggested shipping the row with the switch disabled until the Engine contract. For designer review the switch and the fold are interactive (draft state only); the only control with nothing behind it is the button, and it says why.
  • Row grammar is ng-console's. Label above control, mono 11px recap, Badge / Switch / Select / Table primitives from src/components/ui. Studio_X patterns were ported (recap in the fold, chips, dead-not-hidden options), not components.
