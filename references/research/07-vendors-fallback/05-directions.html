What we take from each

  • A is the surface. One row on Voice & Models, on by default in managed mode, recap in the fold. Reliability stops being an expert feature.
  • B is the fold. "Change backups" opens the per-component table — the Engine's ordered pool, eligibility badges, ineligible options shown but dead.
  • C is one button. "Test failover" in the row and in the Test Strip; the policy itself ships with Agora defaults (slow · down · blocked) and no thresholds in v1.

Why this shape

  • Managed is cheaper than BYO and includes vendor usage — so the default state is covered, and only BYO components ever show a gap.
  • Region eligibility is the real failure mode (pinning costs failover). The gap names the region and offers the two real fixes.
  • Evidence shape matches the SIP ladder's whose-fault badge → Monitor shows "Switched to backup" in the same language.

Dependencies, stated on the row

  • Engine failover contract (868kyqzfy, P1 · Nov) — until then the row can ship as fallback voice + validation + simulation (868kytrkq, Studio P0) with the switch disabled and the caption "Requires Engine failover".
  • Owner call: agent property (default here) vs deployment property. If deployment wins, the row moves next to Hosting Region.
