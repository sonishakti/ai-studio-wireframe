02What a graph loop is

Across LangGraph, AWS’s agentic-patterns guidance, and Google’s ADK, the same shape recurs: model the workflow as a graph (nodes = steps, edges = transitions) and let one edge point backwards — a cycle — so output feeds its own evaluation until a gate passes. Three safeguards keep the cycle from spinning forever:

Evaluator–optimizer core

A generator produces, an evaluator critiques against a rubric, an optimizer revises. Loop repeats until criteria are met — typically converging in 2–3 iterations.

Hard exit conditions

Max-iteration caps and explicit termination predicates are non-negotiable; ADK’s LoopAgent and LangGraph recursion limits exist precisely to bound cycles.

Stall / critic detection

A supervisor (often cheap, often pure code) watches the trajectory and force-exits when metrics stop improving — revising without improving is the classic failure mode.

03The Studio_X graph

Our generator is the whole ship pipeline, our evaluator is the simulated 3-persona focus group, and the rubric is the existing severity/SUS-lite framework — so the graph loop is mostly wiring we already paid for, plus a triage brain and a loop edge.

One round ≈ 7 agents (3 personas + moderator + fix + gate + deploy). TRIAGE and stall detection are pure code — free and deterministic.

Exit conditions, checked in order at TRIAGE: clean (zero P0/quick-P1 — the goal), stalled (metrics flat vs last round — stop paying for revision without improvement), max (default 2 fix rounds; a 3rd test verifies the last batch). Everything left over lands in the report as a P1/P2 backlog, not silently dropped.

04How to run it

Workflow({
  scriptPath: '.claude/workflows/graph-loop.js',
  args: {
    date: '2026-07-21',            // required — workflow scripts can't read the clock
    focus: 'batch-calls CSV mapping',
    slug: 'batch-calls-csv',       // report filename slug
    commit: 'abc1234 one-liner',   // what round 1 tests
    maxIterations: 2               // fix rounds (default 2)
  }
})

Or in plain words: “run the graph loop on what we just shipped.” The old ritual — deploy, run user-test, read synthesis, fix P0s, redeploy, re-test, write the report — is now one invocation.
