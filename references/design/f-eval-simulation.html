F-Eval — evals & simulation, and the end of the pulsing orb

Author simulated-caller tests with pass/fail assertions in the builder, watch them run as a live transcript, and save a real call as a regression test — while closing the trust gap that broke every user test: the “is this thing on?” orb.

◆ Built 2026-07-09 · held for local review commit 0e4c3c2 Table-stakes gap closed (5/5 → shipped) PRD: roadmap-features-prd §3 · F-Eval

Two problems, one feature

The gap: automated evals are table stakes — all five competitors shipped simulated-call testing in ~12 months and Agora had none. The wound: for three consecutive user-test sessions the in-browser “Talk to it” test was the #1 recurring trust break — a pulsing orb with no transcript, no state, no “simulated” label. Both share a root cause and a fix: a test must prove it worked by showing the conversation, not by animating a blob. F-Eval builds the eval feature on a transcript primitive that also replaces the orb on the real Talk surface.

Before — a pulsing sphere + one word of state (“Connected”). “Is this thing on? Did it hear me?” No transcript, no verdict, nothing labeled a simulation.
After — a “Simulated call” banner, explicit Listening → Thinking → Speaking chips, and a streaming transcript you can read, with tool calls noted on the turn.

The eval object model (research)

Composite across Vapi/Retell/ElevenLabs/Synthflow: Suite → Case{ persona(identity·goal·personality), assertions[] } → Run → per-case verdict + transcript + which assertion failed + judge reasoning. Assertions span rubric (plain-language “PASS if…”, LLM-judged), tool-call (right tool, right args), and data-point (field captured). Two whitespace moves nobody ships natively: “save a real call as a test” and closing the orb gap with transcript-as-proof.

Diverge → converge (3 variants)

1 · Suite table + Sheet

The table IS the suite; authoring in a Sheet. Won author-to-value (8.0) + fold-fit (8.4); the only true orb-removal.

2 · Conversation-first

The transcript is the product; verdict anchored onto the turn. Won closes-the-gap (9.0) but can’t scale past a few cases.

3 · Confidence dashboard

“2/3 passing — review before deploy.” Best batch framing; but led with the largest orb and could only author one assertion per case.

Verdict: V1 wins two of three lenses and, crucially, is the only variant that removes the orb entirely — so it wins the load-bearing gap where it counts (V2/V3 re-imported the sphere and merely augmented it). Shipped = V1’s suite table + V2’s inline verdict-coupling (the failing assertion anchored onto the invented-discount bubble) + a shared SimTranscript primitive extracted so the same transcript+state+Simulated treatment lands on the real Talk surface.

What shipped

The feature

  • A Tests section in the builder Test step: a suite table (case · caller goal · assertion kinds · verdict)
  • Add-case Sheet: name + persona + plain-language rubric / tool-call / data-point assertions
  • Run → simulated caller → live transcript → pass/fail verdict; failing case names the broken assertion, anchored to the turn
  • Save a real call as a test — pre-fills persona + transcript, asks only for the assertion

The orb fix (real surface)

  • sim-transcript.tsx: SimTranscript + AgentStateChips + SimulatedBanner, aria-live throughout
  • Folded into the identity-card Talk panel — the bare orb is now joined by the Simulated banner, state chips, and a streaming sample transcript
  • The same primitive powers eval runs — one honesty treatment, everywhere a test runs
  • Events: test_authored · test_run_started/completed · suite_run_all · assertion_failed_viewed · save_call_as_test
