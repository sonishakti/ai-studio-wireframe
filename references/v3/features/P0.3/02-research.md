## Per-vendor copy / avoid

**Vapi** — copy: state both ends of a range right on the control (slider labels "1 … 10", "5 sec … 60 sec"), and use a visible "Deprecated" section for legacy fields kept for compatibility (maps to P0.3.g's read-only API-only row). avoid: burying the default value only in a tooltip with no on-control text at all.

**Retell** — copy: name the default inline in the option's own label ("Remove noise (default)"). avoid: Retell's own gap — no vendor doc shows a numeric-range error UI either, so don't assume one exists to copy from.

**ElevenLabs** — copy: put the numeric bound inside the field label itself ("Files kept in memory (max 10)") and state cross-field constraints in prose next to the field. avoid: ElevenLabs' broad, ungrouped Settings/Advanced tab (chat mode, DTMF, ASR all on one page with no Listen/Think/Speak structure) — the opposite of what P0.3 asks for.

**LiveKit** — copy: one plain sentence stating exactly which fields are ignored and why, right where the realtime path diverges ("InterruptionOptions mostly does not apply... tune interruption on the model itself instead") — this is the direct model for P0.3.d's copy. avoid: LiveKit exposes zero UI at all (everything is code); don't take "hide the control" as license to also hide the reason.

## Gaps

1. **No numeric out-of-range error UI found for any vendor, anywhere in reach.** Refero (3 queries), the existing shot archive, and public docs were all checked; none show a live "value must be between X and Y" state for a voice-AI advanced setting. Reaching one would require signing into a vendor product account — the persistent competitor Chrome profile (`~/.agora-design/chrome-competitors`) came back logged out for both Vapi and Retell this session, and research must never sign in. P0.3.b's copy ("the field error states the range") has to be original work; shot 7 (Vapi's inline min/max labels) and shot 13 (ElevenLabs' bound-in-label) are the closest supporting evidence.
2. **No reset-to-default control found in any voice-AI vendor.** Shot 20 (Fingerprint, via Refero) is a generic SaaS analog, not a vendor precedent — P0.3.f's per-group reset is original design work.
3. **No realtime/mllm pipeline exists in `agent-builder-v3/data.ts` today** (see Rule 0c) — Design/Build needs a fixture (pipeline mode + at least one realtime vendor, e.g. an OpenAI Realtime-style model) before P0.3.d's rainy state can be built or screenshotted.
4. LiveKit's session-lifecycle events (`overlapping_speech`, `agent_false_interruption`) suggest a natural telemetry hook for "Sam presses Save and test and hears the change" (P0.3.a step 4) beyond this row's own event list (`advanced_setting_changed`, `agent_audio_heard`) — flagged for the owner, not added to scope.
5. Vapi's `vapi-03-fallback-transcriber.png` and `vapi-assistant-advanced.png` are the same screenshot under two names from an earlier pass — left both in `research[].note`'s citation but not double-counted as separate evidence.
