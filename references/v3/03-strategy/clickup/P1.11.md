## Job to be done (Sam, a developer)
**Job:** Learn of failures unprompted · job map stage **Monitor** (Sam watches whether it keeps working)
**Umbrella job (P1):** Sam wants to know how each agent is doing with people outside the team, and fix what fails before customers notice.
**Situation:** Sam learns an agent is failing without having to check. Proposed Monitor step, for owner sign-off; blocked while the v3 spec has no events or webhooks.
**Sam wants to:** know about a failing agent as soon as it starts
**So that:** customers are not the first to notice

### P1.11.a Happy path (this is what Sam does)
1. On the agent, Sam turns on a notice for error groups that are new or returned.
2. When one fires, the project's email list gets the agent, the error group, its count and a link.
3. The link opens the error group with the range set (P1.4, P1.10).
4. Sam removes the cause (P1.6) and the notice stops.

### Rainy paths (each needs its own state in the prototype and a frame in Figma)
*   **P1.11.b** The v3 spec has no events or webhooks: Blocked. Until an emitter ships, the header badge (P1.1) and the agents list (P1.5) are the only signal, and the row says so.
*   **P1.11.c** Too many notices: One notice per error group per day, never one per session.
*   **P1.11.d** The error stream is down (G11): One 'Errors unavailable' notice is sent, so silence is never read as health.
*   **P1.11.e** Sam is away: Notices go to the project's email list, not only to Sam.

## Goal (KPI)
**In one line:** Median time from an error's first occurrence to its group being opened under 1 hour.
*   Metric: Time to notice
*   Target: Median ≤ 1 h from first occurrence to error_group_opened, against ≤ 24 h without notices (P1.4)
*   How we measure: First occurrence of a new or returned error group to its first error_group_opened, median; accounts with notices on vs off
*   Counter-metric: Notices muted within 7 d ≤ 20 %
*   Assumption we are testing: Push notices cut time to notice from a day to an hour. Blocked on an events emitter and G11. Method: A/B once unblocked; kill if the median does not drop below 6 h.
