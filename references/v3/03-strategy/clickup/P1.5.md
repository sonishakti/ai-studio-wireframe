## Job to be done (Sam, a developer)
**Job:** Spot the agent in trouble · job map stage **Monitor** (Sam watches whether it keeps working)
**Umbrella job (P1):** Sam wants to know how each agent is doing with people outside the team, and fix what fails before customers notice.
**Situation:** Sam finds which of the team's agents needs attention first.
**Story:** Sam runs six agents and wants to know which one to look at this morning, so no failing agent waits.

### P1.5.a Happy path (this is what Sam does)
1. The agents list shows per row: deployment type, sessions in range, errors badge, last session and a 'No deployment' chip; each cue is a link.
2. Sam sorts by errors; the failing agent rises to the top.
3. The header's project error badge opens project Logs and diagnostics.
4. The shared range control sets the window for every row.
5. Sam opens the row; the agent page opens with the same range.

### Rainy paths (each needs its own state in the prototype and a frame in Figma)
*   **P1.5.b** Sessions are not linked to agents yet (G4): Cell reads 'Not linked yet', never 0.
*   **P1.5.c** Error stream unavailable: Badge column reads 'Unavailable', never 0.
*   **P1.5.d** No sessions in range: Dash, never 0.
*   **P1.5.e** More than 50 agents: Cursor paging; counts load per visible row.
*   **P1.5.f** Counts load slowly: Skeleton per cell; the list is usable first.
*   **P1.5.g** No agents yet: One line plus Create agent.
*   **P1.5.h** Agent never went live: 'No deployment' chip opens the builder's Deployment area.
*   **P1.5.i** Deployment type not recorded (agent created through the API): Type cell reads 'Not set' and links to the ask-once prompt (P0.1).

## Goal (KPI)
**In one line:** Half of agents that show errors get opened within a day.
*   Metric: Agents with errors opened
*   Target: ≥ 50 % within 24 h
*   How we measure: Distinct agents shown with errors on agents_list_viewed that get agent_row_opened {hasErrors: true} within 24 h of first being shown, share of distinct agents shown with errors
*   Counter-metric: Agents list load p75 ≤ 2 s (list_loaded {durationMs})
*   Assumption we are testing: A count badge on the list sends Sam to the right agent. Method: cohort read; kill below 25 %.
