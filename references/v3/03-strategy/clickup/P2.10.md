## Job to be done (Sam, a developer)
**Job:** Rule out the number or caller · job map stage **Locate** (Sam finds the inputs, the session or the cause)
**Umbrella job (P2):** Sam wants to find out what happened in a session, or in a set of sessions, and why.
**Situation:** Sam rules out the number, the carrier and the caller before blaming the agent.
**Story:** Sam suspects the number or the caller, not the agent, so Sam wants every session that number or contact carried.

### P2.10.a Happy path (this is what Sam does)
1. The number page gains 'Sessions via this number' and 'Runs using this number'.
2. In a session, the telephony card shows the number chip and 'Other sessions with this contact (3)'.
3. The contact link opens history with a 30 d contact overlay chip.
4. The agent column shows which agent answered each session, so a re-pointed number reads clearly.

### Rainy paths (each needs its own state in the prototype and a frame in Figma)
*   **P2.10.b** Sessions carry no number or contact: The block is disabled with the reason, unless v2 backs it.
*   **P2.10.c** The number was re-pointed to another agent: The list spans both agents and the agent column shows which.
*   **P2.10.d** The caller withheld the contact: No link.
*   **P2.10.e** The number was deleted: E.164 as text.
*   **P2.10.f** No agent answers the number: 'No agent answers this number', with Go live.
*   **P2.10.g** The number is used only as a run's from number: Says so; 'Runs using this number' leads.
*   **P2.10.h** The session ran over RTC or code, with no number: No telephony card; the RTC transport card shows instead.

## Goal (KPI)
**In one line:** No target yet; number and contact pivots per 100 investigation visits set the baseline.
*   Metric: Number and contact pivots
*   Target: None; baseline read per 100 investigation visits
*   How we measure: monitoring_pivot {carried: number|contact} / investigation visits × 100. Investigation visit: a visit with error_group_opened or session_opened {status: failed} (status needs an allowlist key).
*   Counter-metric: Contact-scoped lists left in < 5 s ≤ 30 %
*   Assumption we are testing: Number and contact views separate number or carrier faults from agent faults; the average Sam checks the number when several sessions fail in a row on inbound.
