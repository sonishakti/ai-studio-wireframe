## Job to be done (Sam, a developer)
**Job:** Read one word per concept · job map stage **Cross-cutting** (A requirement that every step shares, not a step of its own)
**Umbrella job (P3):** Sam wants to look after everything the team's agents share, by hand or from code, and get the same result either way.
**Situation:** Sam follows the documentation while working in the product without translating terms. Cross-cutting requirement, not a job step.
**Sam wants to:** follow the API docs while working in the Console
**So that:** each word points to the same thing in both

### P3.6.a Happy path (this is what Sam does)
1. Every Console string uses the locked vocabulary: integration, deployment, number, run, session, test.
2. Where the Console and the API differ, a tooltip gives the API word: Analysis is structured_output, run is campaign.
3. Renamed pages keep old links working: Credentials opens Secrets, Phone numbers opens Numbers, Campaigns opens Runs.
4. DESIGN.md holds the glossary, and the CI lint stops any banned word before it ships.

### Rainy paths (each needs its own state in the prototype and a frame in Figma)
*   **P3.6.b** The Console and the API use different words: A tooltip gives the API word until the API renames or the owner accepts the gap.
*   **P3.6.c** Sam opens a bookmarked old link (/credentials, /telephony/phone-numbers): Redirect to the renamed page, never a 404.
*   **P3.6.d** An internal event key would reach the UI (app_connected, channel_connected): Never shown; the lint treats frozen event keys as banned in UI strings.
*   **P3.6.e** A locked compound contains a banned word (Go live, RTC channel, App ID, call_policy, RESTful API key, Webhooks): The lint allowlist passes these compounds.
*   **P3.6.f** The documentation still uses an old word: The fix-doc list is applied across KB and doc files; doc links from the Console open pages that use the locked words.
*   **P3.6.g** The card sort fails (under 5 of 5 sort the words right): Integration and deployment go back to the owner before 13 Oct.
*   **P3.6.h** A translated string drifts from the locked word: The lint runs on every locale file, not only English.

## Goal (KPI)
**In one line:** Zero banned words ship in the Console, and no old link ends on a missing page.
*   Metric: Banned words in UI
*   Target: 0 in Console UI strings (CI lint with a compound allowlist, tested on current i18n files first)
*   How we measure: CI lint per build over UI string files: occurrences from each vocabulary never list, minus allowlisted compounds
*   Counter-metric: Old-route hits ending in 404 = 0 (page_viewed routePattern with referrerRoute)
*   Assumption we are testing: Locked words stop Sam misreading integration and deployment. Method: unmoderated 5-person card sort before 13 Oct; pass = 5 of 5 place MCP server, tool, knowledge base under Integration and number, run, code snippet under Deployment.
