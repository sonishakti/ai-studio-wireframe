## Job to be done (Sam, a developer)
**Job:** Know why nothing shows yet · job map: Locate
**Umbrella job (P2):** Sam wants to find out what happened in a session, or in a set of sessions, and why.
**Situation:** When there is nothing to review, Sam finds out whether that is expected or a problem. Proposed to fold into P1.8 and P2.1.k.
**Story:** Sam opens sessions before any exist and wants the one next step, so Sam does not wonder whether something is broken.

### P2.7.a Happy path: what Sam does
1. History with no sessions shows one line and two doors: Talk to agent and Go live.
2. The same state appears inside the embedded lists on the agent, run and number.
3. Talk to agent starts a test; Go live opens the builder's Deployment area.

### Rainy paths: when it goes wrong
*   **P2.7.b** The agent has no deployment: Go live opens Deployment.
*   **P2.7.c** The account is suspended: The minutes banner explains; history stays readable.
*   **P2.7.d** The session source is down: Retry, with filters kept; never shown as empty.
*   **P2.7.e** Seven days after Go live, still no production session: Points to failures and to the number or run.
*   **P2.7.f** Free minutes are nearly used: The minutes banner warns at 80 % and says what stops at 100 %.
*   **P2.7.g** Only test sessions so far: They list with Test tags, and a line says no production session yet, with Go live.
*   **P2.7.h** Filters empty an otherwise full history: Not the first-run state: the list names the emptying filter (P2.2).
*   **P2.7.i** An embedded list is empty for a reason (run scheduled, number with no inbound agent): Says the reason, e.g. 'No agent answers this number', with the matching door.

## Goal (KPI)
**3 in 10 empty-history views lead to talking to the agent or going live.**
*   Metric: Empty-state next step
*   Target: ≥ 30 % of first-run views
*   How we measure: empty_state_viewed {surface: first_run|no_deployment} to talk_to_agent_started {surface: history_empty} or go_live_clicked {entryPoint: history_empty} in the same visit, share
*   Counter-metric: Go live with no heard test ≤ 15 %
*   Assumption: An empty history offering two doors moves Sam on; the average Sam opens history once before the first production session. Kill below 15 %.
