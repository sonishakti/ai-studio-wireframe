## Job to be done (Sam, a developer)
**Job:** Match the bill to sessions · job map stage **Confirm** (Sam checks it is right before going on)
**Umbrella job (P2):** Sam wants to find out what happened in a session, or in a set of sessions, and why.
**Situation:** Sam matches what the team was billed against the sessions that took place.
**Sam wants to:** every session the project paid for in history, even when content is not stored or the agent is unknown
**So that:** counts and bills add up

### P2.6.a Happy path (this is what Sam does)
1. A retention matrix per block decides what each row and detail shows.
2. Zero retention (only when a source says so): metadata, minutes and cost, plus one line on what is never stored.
3. Unlinked (the default for unproven agents): agent name as text, no agent doors.
4. Ephemeral: tagged only when the API returns origin; never counted in agent numbers.
5. Older than 30 days: the row stays and says the content is past retention.
6. Every one of these counts in history and in the CSV.

### Rainy paths (each needs its own state in the prototype and a frame in Figma)
*   **P2.6.b** Retention and origin not returned (G5): Rows read Retention unknown; ephemeral sessions list like any other.
*   **P2.6.c** Sam filters across mixed retention: Counts include every session; content shows only where it exists.
*   **P2.6.d** The agent page and history show different counts: A note explains that tests and ephemeral sessions are not in agent numbers.
*   **P2.6.e** Content has expired: The row stays with minutes and cost, 'Older than 30 days, not available'; expired never reads as not found.
*   **P2.6.f** Cost not returned (G4): The cost cell reads not reported yet, never $0.
*   **P2.6.g** An ephemeral session failed with no agent to look at (EP-R): The row lists as 'Agent not linked' with Status detail, and its errors sit in the project Logs 'Agent not linked' bucket.
*   **P2.6.h** The agent was deleted: Its sessions stay in history with the agent as text and still count.

## Goal (KPI)
**In one line:** Each month, listed session minutes match invoiced minutes within 1 percent.
*   Metric: Honest rows
*   Target: Listed session minutes = invoiced minutes ± 1 %, monthly (PRD)
*   How we measure: Billed minutes by agent_session_id (metering, G9) against history rows including zero retention and ephemeral, monthly ratio. Blocked on G4 billable_seconds and G9; interim: none.
*   Counter-metric: Billing tickets about missing sessions = 0
*   Assumption we are testing: Listing every billed session, including zero retention, ephemeral and unlinked ones, keeps missing-session tickets at 0; the average Sam reconciles history against the bill at month end.
