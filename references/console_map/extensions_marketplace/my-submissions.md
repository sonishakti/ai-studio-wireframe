# My Submissions
**URL**: https://console.agora.io/extensions-marketplace/my-submissions
**Section**: Extension Marketplace
**Accessed**: 2026-05-21T00:00:00Z
**Access Restricted**: false

## Purpose
Submission management page for developers who have published or are preparing to publish extensions to the Agora Extensions Marketplace. Allows developers to create and track their own extension submissions.

## Content Hierarchy

- **Tab navigation**: Marketplace | My Submissions (active)
- **Heading**: "My Submissions"
- **Action button**: "Create" ⚠️
- **Content**: Empty state — "No submissions yet"

## Interactive Elements (observed, not activated)

- "Marketplace" tab button → /extensions-marketplace
- "My Submissions" tab button (active)
- "Create" button ⚠️ — opens submission creation flow (not activated)

## Notes
- Account has no extension submissions.
- The "Create" button is the entry point for submitting a new extension to the marketplace.
- URL changes to /extensions-marketplace/my-submissions when this tab is active (unlike extension detail side panels which did not change URL).
