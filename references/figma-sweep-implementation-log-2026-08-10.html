Flagged — in the designs but deliberately not copied

  • flag Hosting-region helper copy. The frames say “We’ll store your project’s data in this region. Regions cannot be changed later.” That is Console’s project-storage rule, not Agora’s agent geofence — the geofence is per-agent, changeable, engine-only, and exclusions only exist under Global (verified 2026-08-03 against docs.agora.io). The build keeps the verified copy and the Global-only exclusion rule under the frame’s “+ Add Exclusions” affordance.
  • flag Model names. Frames illustrate “GPT-5 nano + Flash v2.5”, but the same board’s Deployment Summary shows “gpt-4o-mini · nova-2 · turbo”. The frames disagree with themselves, so the mock catalog (GPT-4o family) was left alone rather than churned.
  • flag Test strip. Not in these frames, but it’s the 2026-07-30 owner lock (Talk · Run simulations · verdict, sticky under the header) — kept. Its Talk button now lands on the rail’s Test Agent tab, which IS the frames’ talk surface.
  • flag New Campaign modal (3023-103726). The board carries two patterns — this modal and the inline run editor (2867-111374). The build keeps the richer inline editor (also Figma) and aligned its vocabulary (Download CSV Template, “Learn how {{dynamic vars}} work”, Save Run). The modal’s “Call delay (ms)” lives as agent-level “Minimum interval between calls (ms)” in Advanced Settings.
  • flag Create-agent backdrop (2861-59988). Behind the dialog the frame shows an /agents landing (“Deploy your first AI agent in minutes”, Import Agent · Create Blank Agent, a sidebar with “RTE Analytics”, a “Concierge” topbar). Frame sidebars are non-canonical per project memory, and that landing is a different surface from today’s locked /agents — only the dialog itself was aligned. Needs an owner call before touching the landing.
  • flag Speech-sheet extras. Filter words, Selective attention locking, and Max wait duration ship today but aren’t in frame 2916-3435. Kept (below the frame’s fields — the sheet scrolls); deleting shipped controls wasn’t in the ask.
