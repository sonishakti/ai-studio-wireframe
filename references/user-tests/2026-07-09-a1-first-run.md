## Durable learnings

1. **The arrival moment is the product's first promise — it must be kept by the very next
   click.** Copy that gets ahead of the interaction (mic claims before a mic exists)
   converts the best moment into the first trust break.
2. **A confirmation dialog is a manifest of truth** — any figure it shows must derive from
   the same source as the setting it confirms. Two defaults = a lie in the safety surface.
3. **Session-over-session metrics work**: SUS 72→74.7, sentiment +0.42→+0.51 — the protocol
   is detecting real deltas, and TTFA-interaction regressions localize seams precisely.
